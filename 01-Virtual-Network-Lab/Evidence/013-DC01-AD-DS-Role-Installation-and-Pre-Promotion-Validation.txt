4. AD DS ROLE INSTALLATION
================================================================================

The Active Directory Domain Services role was installed using:

Server Manager
→ Add Roles and Features
→ Role-based or feature-based installation
→ DC01
→ Active Directory Domain Services

Windows automatically selected the required AD DS management components,
including:

- Group Policy Management
- Remote Server Administration Tools
- AD DS and AD LDS Tools
- Active Directory module for Windows PowerShell
- Active Directory Administrative Center
- AD DS snap-ins and command-line tools

No unrelated server roles or features were manually added.

Automatic restart was disabled so that any required restart could be handled
and documented deliberately.

Installation Result:

Configuration required. Installation succeeded on DC01.

IMPORTANT:
Installing the AD DS role did not promote DC01 to a domain controller.
Domain-controller promotion remained a separate configuration step.

================================================================================
9. KEY TECHNICAL OBSERVATIONS
================================================================================

1. Installing the AD DS role does not automatically make a Windows Server a
   domain controller.

2. A server can have the AD DS role binaries and management tools installed
   while remaining a standalone WORKGROUP server.

3. Domain-controller promotion is a separate configuration process that will
   establish the Active Directory forest and domain.

4. Active Directory depends heavily on DNS for locating domain controllers and
   other AD services.

5. Public DNS resolvers were not configured directly on DC01 before promotion.

6. Static addressing was preserved because infrastructure services such as
   Active Directory and DNS require predictable network addressing.

7. Configuration was verified with PowerShell rather than relying solely on
   Server Manager status messages.
