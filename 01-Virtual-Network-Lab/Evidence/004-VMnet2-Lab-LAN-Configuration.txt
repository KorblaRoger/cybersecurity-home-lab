PROJECT 01 — VIRTUAL NETWORK LAB

Evidence 004:
VMnet2 Internal Lab Network Configuration


OBJECTIVE

Create a dedicated host-only virtual network for the
cybersecurity lab.


NETWORK DESIGN

Network Name:
VMnet2 / LAB-LAN

Network Address:
10.10.10.0/24

Subnet Mask:
255.255.255.0

Host VMware Adapter:
10.10.10.1

VMware DHCP:
Disabled

Network Type:
Host-only


RATIONALE

A host-only network was selected to provide an isolated
environment where virtual machines can communicate with
each other and the Windows host without being directly
connected to the external physical network.

VMware DHCP was disabled so IP configuration can initially
be performed manually as part of the networking exercises.

Gateway    10.10.10.254 (reserved for future use)

VERIFICATION RESULTS

The VMware Network Adapter VMnet2 was successfully assigned
10.10.10.1/24.

The Windows routing table contains a directly connected route
for 10.10.10.0/24 through VMnet2.

VMware DHCP remains disabled and VMnet2 has no default gateway,
as expected for the isolated LAB-LAN.

Result: Configuration successful.
