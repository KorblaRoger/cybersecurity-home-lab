PROJECT 01 — VIRTUAL NETWORK LAB
Evidence 003: VMware Network Discovery

Objective:
Identify the IPv4 addressing and routing configuration of VMware
virtual network adapters before redesigning the home lab.

Observed VMware Networks:

VMnet1
Host Address: 192.168.241.1/24
Network:      192.168.241.0/24

VMnet2
Host Address: 192.168.117.1/24
Network:      192.168.117.0/24

VMnet3
Host Address: 192.168.128.1/24
Network:      192.168.128.0/24

VMnet8
Host Address: 192.168.112.1/24
Network:      192.168.112.0/24

Observation:
Each VMware network appears as a directly connected network on
the Windows host. No default gateway is configured on the VMware
host adapters.

Important:
The "DHCP Enabled: No" value shown by ipconfig applies to the
Windows host adapter. It does not establish whether VMware's
DHCP service is enabled for guest virtual machines.
