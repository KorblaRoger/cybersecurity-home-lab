Evidence 010 - UBUNTU01 Pre-Dual-NIC Baseline
================================================

Stage:
3D - Dual-Homed Ubuntu Networking

Purpose:
Verify the known-good Stage 3C network state before adding a second
virtual network adapter to UBUNTU01.

Current Configuration:
Hostname: emrok-ubuntu01
Internal Interface: ens33
Internal IPv4 Address: 10.10.10.40/24
Internal Network: VMnet2 / 10.10.10.0/24
Default IPv4 Route: None

Validation Results:
- ens33 is UP.
- ens33 retains static address 10.10.10.40/24.
- NetworkManager shows ens33 connected through Wired connection 1.
- The routing table contains a directly connected route for 10.10.10.0/24.
- No default IPv4 route is installed.
- Windows VMnet2 host 10.10.10.1 is reachable.
- Ping test to 10.10.10.1 completed with 0% packet loss.
- Route lookup for 8.8.8.8 returned "Network is unreachable."

Conclusion:
The Stage 3C VMnet2 static baseline remains operational.

UBUNTU01 can communicate with the directly connected 10.10.10.0/24
network but has no route to external IPv4 networks.

This state provides the pre-change baseline for adding a second
VMware network interface connected to VMnet8.
