# Cybersecurity Home Lab Portfolio

I'm Roger Kumedzro, a CompTIA Security+ certified cybersecurity enthusiast working toward a career in security operations and security analysis.

I started building this home lab to go beyond studying cybersecurity concepts and better understand how networks, operating systems, and security technologies work together.

My previous cybersecurity training and security analyst internship introduced me to SIEM monitoring, log analysis, phishing investigations, and vulnerability assessment. This lab allows me to build on that experience through hands-on configuration, troubleshooting, and validation.

I'm documenting both what works and the challenges I encounter, because understanding *why* something works is just as important to me as getting it working.

## Home Lab Projects

### 01 — Virtual Network Architecture & Security Lab

**Status: Complete**

My first project establishes the network and system infrastructure for future cybersecurity exercises.

I configured an isolated VMware host-only network alongside NAT connectivity, tested communication between Windows and Ubuntu systems, and worked through dual-network-interface configuration challenges.

I also deployed Windows Server, promoted it to an Active Directory domain controller, validated DNS functionality, and configured network time synchronization.

Throughout the project, I recorded command outputs, troubleshooting steps, screenshots, and validation results to demonstrate what I configured and how I verified it.

## How I Document My Work

I want my documentation to explain not just what I did, but why I did it and how I confirmed the results.

Where applicable, each project includes:

- **README:** Objectives, configurations, validation, troubleshooting, and lessons learned
- **Evidence:** Relevant command outputs and validation records
- **Commands:** PowerShell and Bash scripts or commands
- **Screenshots:** Visual records of important configuration and verification steps

I review materials before publishing to avoid exposing credentials, sensitive identifiers, or unnecessary private system information.
